3. Кому передаются данные

Мы не продаём данные и не передаём их для рекламы. Обрабатывают только сервисы, без которых работа невозможна:

  • GitHub Pages — хостинг этого сайта;
  • сервис аналитики — обезличенная статистика, если подключён;
  • Pinterest — если вы перешли на сайт по ссылке из нашего пина: платформа обрабатывает данные по своим правилам.

Каждый из этих сервисов обрабатывает данные по собственной политике конфиденциальности.

Часть сервисов находится за пределами Европейского союза — например, хостинг сайта и мессенджеры. Передача происходит на условиях этих сервисов и с вашего согласия, которое вы даёте, обращаясь к нам через них.
